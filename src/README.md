# Source Code (`src/`)

Este diretório contém o código-fonte da aplicação de exemplo utilizada no laboratório.

## Aplicação

- **`app.py`** — Aplicação web mínima em Python (Flask) para fins educacionais.
- **`requirements.txt`** — Dependências Python.

## Objetivo

A aplicação serve como artefato de estudo para containerização (Docker),
orquestração (Kubernetes / AKS) e deploy em Azure App Service ou Container Apps.

Não se trata de uma aplicação de produção — é um projeto didático e reproduzível.
